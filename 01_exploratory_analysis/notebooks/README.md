# notebooks

One Jupyter notebook per question from the checklist in the parent README.

- Name: `NN_topic_initials.ipynb`, with `NN` the checklist number (for example `03_hour_of_day_profiles_ab.ipynb`).
- First cell: a short statement of the question and which files are used.
- Load data with the snippet in the root README. Use `value_clean` and blank `quality_flag` rows.
- Last cell: what you found, in three sentences or fewer, then copy it into `../findings/`.
- Save charts to `../figures/` with `savefig`, not only in the notebook.
- Clear outputs before committing large notebooks.
