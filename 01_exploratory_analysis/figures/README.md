# figures

Saved charts (PNG, 150 dpi or more). Each figure must be used in a finding.

- Name: `NN_plant_topic.png` (for example `03_plantA_hour_of_day_profiles.png`).
- Title, axis labels with units, plant and date range on every chart.
- Show gaps as gaps. Never draw a line through missing data.
- Mark flagged data (dead, stuck, outage) with hatching or a different colour.
