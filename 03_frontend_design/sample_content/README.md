# sample_content

Realistic content for mock-ups, taken from events in the data (anonymized).

| File | What it is |
|---|---|
| `sample_alerts.csv` | Eight sample alerts covering every priority plus Suppressed and Data issue, with title, detail, status and start time |

Example plain-language text for the alert detail screen: "Freezers UF-3 and UF-4 both rose to about 49 F at 2:45 a.m. last night, against an 18 F setpoint. The same spike has happened at the same time every night this week and it is getting larger."

Add more samples here as designs need them (notification messages, digest emails, evidence tables).
